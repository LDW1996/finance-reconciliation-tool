财务对账工具使用说明

一、启动与更新
1. 等任务结束后再更新。将新压缩包完整解压到新文件夹，关闭旧程序。
2. 双击新文件夹内“财务综合业务平台.exe”，不要使用指向旧版本的快捷方式。
3. 浏览器会自动打开；未打开时访问 http://127.0.0.1:8765 。页面未更新时按 Ctrl+F5 刷新。
4. 顶部菜单为“Excel对账”“iLog批量解锁”“账号管理”。
5. iLog 功能需要联网，并安装 Chrome 或 Microsoft Edge。
6. 如被 Windows 安全策略拦截，请交由公司 IT 核验发布来源，不要直接关闭系统防护。

二、Excel对账
1. 上传两家公司往来明细，等待自动检查。
2. 核对匹配字段、金额字段和容差，点击“开始分析”，下载对应结果。
3. 支持“对账结果”和“原表标色”两种模式。
4. 必须包含“公司代码or伙伴公司”“分配”“原币金额”，且仅有两家公司代码。
5. Excel 对账在本机处理，不向 iLog 上传表格。

三、账号管理
1. 添加公司授权的账号和密码；不同电脑需分别登记。编辑时密码留空表示保留原密码。
2. 密码加密保存在本机；持有本机数据目录和密钥的人仍可能读取，请限制访问权限。

四、批量解锁
1. 选择主账号，可开启“查无订单时兜底”并选择另一个账号。
2. 单号分别粘贴到“小锁”“大锁”输入框，支持换行、逗号和空格分隔。
3. 点击“校验单号并核对清单”，检查账号、单号及锁类型；重复项不执行，格式异常需修改。
4. 勾选授权并确认解锁后，会真实登录 iLog 并修改锁状态，不是演示。
5. 仅主账号明确查无订单时使用兜底账号；超时、登录失败、多条匹配或解锁失败不切换账号重试。
6. 逐笔结果包含实际账号、平台响应、状态复查及截图，可导出。
7. 单笔失败或待核实会记录原因并继续后续项，不会自动重复提交解锁。任务结束后查看“待人工处理”或导出结果，逐条核实异常。只读复查失败最多额外重试三次。
8. 暂停或取消只影响后续项，当前单继续完成；不要强行关闭程序或断网。
9. 提示历史提交时先核对历史记录，不要删除防重复凭据强行重跑。
10. 支持纯数字或不完整号码，自动处理平台查询返回的全部需解锁记录，无需逐条勾选，结果按业务号显示。原本已解的跳过；跨页结果或未知锁状态不解锁。

邮件收款匹配
1. 打开并登录 Windows 经典版 Outlook，进入“邮件收款—邮箱与邮件”，点击“连接 Outlook”并选择收件箱或子文件夹。不支持新版 Outlook；不需要再次登记邮箱密码。
2. 开启自动读取后，先分批补扫历史，再读取新增邮件。工具进程与 Outlook 需保持运行；勾选“启动后恢复自动读取”可在下次启动时恢复。
3. 图片和 PDF 附件会在本地识别，不上传到在线识别服务。点击字段的来源页码可对照凭证；付款人、日期、金额均为待核对候选，不自动核销或解锁。不发送、不移动、不删除邮件，不设置已读。
4. 历史补扫按批继续，遇到失败可查看提示或重新补扫。邮件列表每页显示 50 封，可翻页及搜索全部记录；累计扫描可能包含重复邮件，本地已保存显示去重后的总数，待识别显示附件处理队列。
5. 邮件内容加密保存在本机数据目录的 mail 子目录。清空本地记录只清本机缓存，不影响 Outlook 邮件；先停止定时读取并等待完成。
6. Mac 或未安装 Outlook 时可导入不超过 25 MB 的 MSG/EML 邮件；旧记录需要重新导入才能读取附件。单附件上限 10 MB，最多处理 20 个附件、PDF 前 10 页；超限或失败会显示原因。可点击“识别附件”重试失败项。真实公司邮箱连接仍需在 Windows 财务电脑实测。
7. “收款匹配—配置在线来源”填写在线 Google 表格完整链接，首次选择管理员提供的服务账号 JSON。请管理员启用 Google Sheets API，并将在线表以编辑权限共享给界面显示的服务账号邮箱。授权加密保存在本机，不要把密钥发给无关人员或放入安装包。
8. 点击“读取在线流水”，默认查看未识别收款。每笔显示前三个邮件付款候选和 0–100 分匹配分数，核对付款人、日期、金额及原凭证后“确认关联”。分数仅供参考，不等于已核销。
9. 点击“回写已确认关联”，核对总数后提交。写入专用邮件备注、分数及可搜索的邮件信息，保留原备注和核销状态。冲突跳过并说明原因，重复内容不重复写入。回写期间请勿排序或增删在线表行。
10. “同步记录”可查看修改前后内容、时间和结果。写入超时先读取在线表核对，不盲目重试；记录在本机保留。手工导入流水、导出匹配结果作为验证和备用入口。

五、历史与数据保留
1. “历史记录”可查看及导出旧任务。
2. “保存设置”默认截图保留 90 天、正常结束任务保留 365 天，可修改或关闭自动清理。
3. 打开页面、查看历史或新建任务时检查，每 24 小时最多一次；有任务执行时延后。
4. 运行中、暂停中、待核实任务及防重复凭据不会自动删除。
5. 手动清理先预览再确认，不会修改 iLog 订单。
6. 数据目录：%LOCALAPPDATA%\FinanceReconciliation 。账号数据库与 accounts.key 一起备份，不要发给无关人员。
7. 更新程序不会主动覆盖数据目录；换电脑时记录和防重复保护不会自动同步。

六、异常处理
1. 连接中断时先刷新结果，不要重复新建任务。
2. 重启后未完成任务暂停，执行中的单号标记待核实；先核对 iLog 状态再继续。
3. 不要仅凭“已提交”认定成功，以平台响应和复查结果为准。
4. iLog 页面或权限变化可能导致停止，请保留结果和截图反馈维护人员。

邮件容量保护与更新
- 管理 → 保存设置 → 邮件存储，可查看占用并调整规则。默认邮件容量 10 GB、磁盘至少剩余 5 GB、识别积压暂停线 500 封。
- 空间不足时暂停新增读取，不删除已有邮件；释放空间或提高容量后，再点读取一批继续。自动读取开启时会在后续检查中重试。识别积压时等待队列消化即可。
- 这一版不自动清理邮件或凭证。容量仅统计本地邮件数据库，未包含 Outlook/PST 文件和解锁记录；识别过程可能有临时空间增长。
- 更新前关闭旧程序，再解压新版并运行。同一电脑、同一 Windows 用户的数据保存在 %LOCALAPPDATA%\FinanceReconciliation，与程序目录分开；不要删除该数据目录或密钥。
- 跨电脑或跨用户不会自动迁移。备份应在关闭程序后复制整个数据目录。旧邮件、账号及读取进度会沿用，未完成的识别任务会恢复。

新版邮件提速测试
- 本版支持最多四路识别、同内容附件复用、文字 PDF 保守提取，以及识别进行中重新选择邮件目录。修改目录前先关闭自动读取并等待当前读取批次结束；后台识别可继续。
- 更新前退出旧程序，并复制整个数据目录及密钥作为备份。新版沿用原目录，已有邮件、识别结果、确认关联和原范围读取断点保留。请勿同时运行两个版本。
- 在“邮箱与邮件”的收取设置中展开“本次启动 · 识别处理”，查看最近60秒处理量、OCR页数、复用、未变邮件跳过和耗时。导出性能 JSON 可用于比较，文件不包含邮件正文或附件内容；统计在重启后重新开始。
- 第一次读取完整且 Outlook 支持可靠变更标识的邮件，再次补扫时会跳过未变化的正文和附件下载。不支持该标识或此前读取不完整时仍正常读取，避免漏数据。
- 比较前后版本时使用相同目录、日期范围和同一份备份副本；原任务尚未完成时不要为测试点击“重新补扫”。读取/下载、识别、保存时间分别观察；并发累计耗时有重叠，不能直接相加。
- 队列较满时先暂停读取，积压下降到暂停线的一半后自动提前继续。仅在自动读取开启、空间允许且识别没有异常时生效。

历史邮件释放磁盘空间
1. 关闭自动读取，进入 管理 → 保存设置 → 邮件存储。
2. 点击“预览存储优化”，等待显示可移除的历史预览及重复附件估算。
3. 保持勾选“优化后整理数据库，释放磁盘空间”，点击“确认优化”。
4. 保持程序运行，等待完成。大库可能需要较长时间；空间不足时会提示尚未整理，可释放空间后重试。
原始凭证、邮件文字和确认关联均保留。新预览只在查看时生成，缓存默认最多 256 MB。已有旧数据需要执行上述优化，升级本身不会自动缩小数据库。
