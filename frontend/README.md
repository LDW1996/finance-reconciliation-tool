# 前端结构

- `src/App.vue`：统一应用导航和 URL hash 页面切换。切换页面时保留本次打开期间的对账文件。
- `src/views/ReconciliationView.vue`：原有 Excel 对账页面，保留详细导出、原表标色和中英印尼语。
- `src/views/UnlockView.vue`：批量解锁工作台与账号管理界面。费用解锁对应小锁，订单解锁对应大锁。
- `src/components/FileDrop.vue`：复用的 Excel 上传组件。
- `src/services/api.ts`：现有真实对账 API。
- `src/style.css`：共享主题、应用导航和响应式布局。

## 当前阶段

默认打开 Excel 对账；顶部菜单可切换 iLog 批量解锁和账号管理，也支持 `#excel`、`#unlock`、`#accounts` 直达。

页面已整合苹果风浅色主题、宽屏对账布局、语言下拉选项和金额容差上下调节按钮修复。

解锁页面已连接后端真实任务。确认窗口明确提示真实操作，勾选授权后创建任务，后台串行登录、查询、解锁并复查。不要把生产单号当演示数据提交。
账号管理由后端 SQLite 保存，不依赖系统钥匙串。密码使用 Fernet 加密，不返回原密码到浏览器。任务及逐笔结果也保存在本机 SQLite，刷新后恢复最近任务。
同类单号自动去重，跨大小锁的同一单号在核对框提示，会分别处理。
输入框下展示重复单号及次数；核对弹窗以大小锁两个 Tab 展示原文、识别结果和异常建议。异常未修正或未勾选真实操作授权时不能开始。格式校验不等于单号存在性校验。

独立的只读登录与提单查询脚本见 `backend/ILOG_QUERY.md`。
单笔解锁与结果核实脚本见 `backend/ILOG_UNLOCK.md`，默认只读，真实提交需要显式参数。平台确认成功与复查确认无锁分别记录，不把不确定结果当成功。

账号可新增、编辑和删除。编辑时新密码留空保留原密码；取消或关闭窗口会清空新密码输入。旧版浏览器账号元数据会迁移到后端，不再依赖浏览器存储。

账号数据目录：Windows 为 `%LOCALAPPDATA%/FinanceReconciliation`，Mac 为 `~/Library/Application Support/FinanceReconciliation`。目录内的 `accounts.sqlite3` 与 `accounts.key` 需要一起保留；替换程序不会覆盖它们。可用 `FINANCE_RECONCILE_DATA_DIR` 指定目录。实际账号不会打进代码或安装包。

## 真实任务保护

服务端复验清单和授权，同一确认请求幂等；一次仅允许一个未结束任务。单项异常记录后继续下一项，不重复提交解锁。手动暂停或重启恢复后的继续只处理等待项。
支持主账号未找到时使用一个兜底账号，默认从另一个已保存密码的账号中选择；可关闭或手动选择。二次确认列出两个账号，服务端校验兜底账号与主账号不同且已保存密码。
仅 `not_found` 且 `submitted=false` 才兜底，登录失败、超时、多条匹配、提交结果不明和平台拒绝均不会切换账号。两边均查无记录则标记待核实并继续后续项。

支持不完整号码和纯数字查询；同一查询返回多条业务时，无需额外逐条确认，后端按平台记录 ID 选择、提交、复查，结果按业务号逐条展开。页面、历史详情和 CSV 均包含业务号。跨页或未知锁状态不解锁。
逐笔显示实际账号和两次查询路径；确认请求幂等键包含兜底账号。进度、截图和导出基于实际执行账号，防重复记录沿用实际账号及平台记录 ID。
暂停和取消只影响后续项，当前已开始的单会完成并留下结果。服务重启后未完成任务暂停，执行中的单标记待核实，不自动重放。
本机 `unlock-results/submitted` 以账号、平台记录 ID、锁类型记录提交保护，兼容旧的单号保护记录；跨电脑不自动共享，重新锁定后的合法再次解锁需要人工核实历史记录。
本机需要安装 Chrome 或 Edge。Windows 打包配置已加入 Playwright 驱动数据，但 Windows 实机运行、权限及安全软件兼容仍需验证；不宣称打包已通过。

## 历史与保留期限

工作台顶部“历史记录”支持分页查看任务、查看逐笔详情及导出历史任务，不会替换当前执行任务。
“保存设置”默认截图 90 天、任务结果 365 天，可修改期限和关闭自动清理；手动清理需先预览数量再确认。
自动清理在打开页面、查看历史和新建任务时检查，每 24 小时最多一次；后台未运行时不清理，正在执行任务时延后。
仅清理正常结束且到期的任务结果；运行中、暂停中、待核实任务及其关联证据保留。已过期截图显示“已过期清理”。
`unlock-results/submitted` 防重复凭据及过期确认请求的防重放标记不参与清理。账号数据、账号密钥和 iLog 订单不会被清理。
