# iLog 执行模式

- 标准模式默认开启，保留原来的提交后只读复查和有限重试。
- 快速模式保留查询、选择 ID 校验、确认窗口校验、持久化防重复提交。仅取消提交后的复查，明确 success=true 记为 platform_accepted；拒绝和不明确响应不记成功。
- 模式通过 verify_after 保存到任务，执行时读取任务保存值。旧任务字段缺失时默认 true。快速模式参与请求幂等绑定，不允许同一确认请求切换模式重放。
- 单笔、批量和航次均支持。页面清理只关闭 ExtJS 结果提示，失败则丢弃脏会话，保留平台已返回的结果。正常批次继续复用登录。
- 页面、任务详情和 CSV 区分“平台返回成功（未复查）”与原来的已复查结果；CSV 保留原列并追加执行模式。
- 未连接真实 iLog 执行解锁，无法承诺实际提速比例。Windows 及平台实际响应仍需业务验收。
- 本轮不修改邮件数据、邮件识别、流水匹配及历史任务内容；不自动提交或推送。
