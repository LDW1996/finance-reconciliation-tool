# 邮件收款匹配使用说明

这项功能帮助财务从邮件中寻找银行收款的付款依据。程序根据付款金额、付款日期、付款人给出候选，财务核对后保存关联，再单独回写在线流水。不会自动核销或修改收款状态。

## 一、先分清三种“更新”

| 功能 | 什么时候发生 | 更新什么 |
| --- | --- | --- |
| 读取在线流水 | 点击“读取在线流水” | 从 Google 表格获取最新流水，保存到本机供匹配 |
| 刷新匹配结果 | 页面可见且空闲时约每 5 秒检查一次；也可点“刷新结果” | 查询本机已保存的流水、邮件识别和核对结果，不下载 Google 流水 |
| 自动读取邮件 | 在“邮箱与邮件”开启后，按选定间隔运行 | 从经典版 Outlook 获取邮件和附件；历史补扫会分批接着读 |

回写在线表时，程序还会读取在线数据做提交前核对和提交后验证。因此在线表并非每秒刷新，也不是只在“读取在线流水”时才会被访问。只浏览匹配列表不会每 5 秒读取 Google 表格。

在线来源显示的“更新于”是上次成功读取在线流水的时间，不是页面每次刷新时间。银行表新增或修改收款后，要再次点击“读取在线流水”。

## 二、第一次使用：准备邮件

### 财务 Windows 电脑

1. 打开并登录经典版 Outlook，再启动工具。
2. 进入顶部“邮件收款”，切换“邮箱与邮件”。
3. 点击“连接 Outlook”，选择实际接收付款通知的邮箱文件夹。
4. 设置历史范围，使其覆盖需要核对的收款日期。每批封数表示一次读取多少封，不是总共只读这么多。
5. 开启“自动读取”，选择检查间隔。历史邮件会分批补扫，完成后继续读取新增邮件。
6. 如需下次启动工具时恢复，勾选“启动后恢复自动读取”。电脑、工具和 Outlook 需保持可用。
7. 等待附件识别完成，再到“收款匹配”核对。

### 本地验证

Mac 不支持这套经典版 Outlook 自动连接。可以在“邮箱与邮件”点击“导入验证邮件”，选择 MSG 或 EML，等待图片和 PDF 附件识别完成，验证后续流程。

页面显示“自动读取未开启”，就表示目前没有定时收取新邮件。已经导入并识别的样例仍可匹配。

## 三、日常使用：按这个顺序操作

### 第 1 步：读取最新流水

进入“收款匹配”，点击“读取在线流水”。成功后检查工作表名称、收款数量和更新时间。

“已配置”表示已保存链接及授权文件，不等于已经读取到最新数据。如果尚未配置，先由管理员完成“配置在线来源”。日常无需反复上传 JSON。

### 第 2 步：筛选要核对的收款

常用控件：

- **查找收款**：输入流水参考号、付款人或银行摘要中的文字，点“查询”或按回车。搜索整份已读取的流水，不限当前页。
- **收款范围**：日常优先选“未识别收款”；“未结清收款”用于查看未结清记录；“全部收款”也包含 CLOSED 等已处理记录，适合历史验证。
- **匹配分数**：先看“90 分及以上”，再看“70 分及以上”；“全部分数”也会显示低分或没有候选的收款。
- **更多条件**：日期默认允许前后相差 3 天，可调整；默认按匹配分从高到低排列，也可切回流水原始顺序。

注意：90 分以上只是优先核对的线索，不代表自动认定匹配正确。70 分有可能仅金额、日期一致，而付款人完全不同。

### 第 3 步：打开“核对邮件”

点击某笔收款右侧的“核对邮件”，会打开侧边面板：

1. 顶部是银行流水金额、付款人、日期及参考号。
2. 左侧列出这笔收款的候选付款凭证。点击不同候选可切换，默认最多显示前 3 条；必要时可展开至最多 20 条。
3. 右侧并排对照银行流水和邮件凭证的金额、日期、付款人。黄色行表示该项缺失、不完全一致或需要核实。
4. 向下滚动查看提单号、发票号等业务信息、建议备注、邮件主题、发件人及附件来源。
5. 需要核对证据时，展开“查看原文证据”，或点“查看原邮件”检查邮件正文和付款附件。

同一封邮件可能有多个附件或付款凭证，所以“候选凭证 2 条”不一定是两封独立邮件。也可能有多笔银行收款同时匹配到同一份凭证，应结合业务信息判断，不能仅凭金额相同批量确认。

### 第 4 步：保存核对结论

- **确认关联**：确认当前选中的邮件凭证确实对应这笔收款，保存到本机。此时还没有修改在线表。
- **暂不关联**：当前候选不足以确认，先把这笔收款标记为暂不关联。该操作作用于整笔收款，不是只排除左侧一条候选。
- **重置核对**：把这笔收款恢复为待核对。
- **关闭面板**：不自动保存新的确认结论。

建议先核对一笔最明确的收款，熟悉操作，再处理更多记录。

### 第 5 步：回写在线流水

1. 核对完成后，点击顶部“回写已确认关联”。
2. 查看弹窗数量：处理的是当前在线台账全部已确认关联，包括其他页面、其他筛选范围的记录。
3. 确认提交后，程序按流水参考号重新定位并核对日期、金额等信息。
4. 只回写专用邮件关联备注、匹配分数及邮件检索信息，不修改核销状态。提单号等号码来自所确认的邮件候选，并保留需要核对的关联说明。
5. 查看逐笔结果；必要时打开在线表检查对应行。

回写期间请勿排序、增删或编辑目标流水行。其他人员已有的备注不直接覆盖；流水重复、内容变化或来源不确定时会跳过并说明原因。重复回写已一致的内容不会重复追加。

### 第 6 步：查看“同步记录”

记录保存在当前电脑，可查看时间、流水参考号、结果、说明，并展开修改前后内容。

- **已写入**：提交后回读核对一致。
- **无变化**：在线内容已一致，本次无需修改。
- **失败**：未完成处理，按说明检查权限、重复参考号、数据变化或已有备注。
- **待核实**：提交或回读过程中连接中断，尚不能确定结果。先查看在线表及记录，再决定下一步，不要把它当作明确失败直接反复提交。

## 四、你截图里的数字怎么理解

- **当前收款范围 3,544**：当前选择“全部收款”后的范围数量。
- **有邮件线索 49**：其中 49 笔有候选，不代表已经确认，也不一定是 49 封不同邮件。
- **暂无邮件线索 3,495**：在当前已识别邮件及匹配条件下，没有候选。可能尚未读取相关邮件、附件无法识别，或条件不符合。
- **已确认关联 0**：当前范围还没有财务确认的关联。
- **4 笔筛选结果**：你选择了“90 分及以上”，符合这个分数条件的只有 4 笔。上面的概览数字在分数及关键词过滤前统计，所以不会跟着变成 4。
- **已跳过 6 行**：这些行没有有效日期或金额，未进入匹配；不是 6 笔已确认收款。

## 五、最短操作顺序

准备邮件并等待识别 → 读取在线流水 → 筛选收款 → 核对邮件凭证 → 确认关联 → 回写已确认关联 → 查看同步记录。

“本地文件验证 / 导出”是备用入口，可导入 Excel/CSV 或导出匹配建议。日常使用在线流水时，不需要反复做文件导入导出。
