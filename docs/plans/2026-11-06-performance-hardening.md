# 四项兼容性优化

范围：不改对账算法、原表标色和已有公式、匹配分数、旧数据和权限。

1. Excel 路由保留异步上传，在线程中执行检查、计算与导出；每份限制50 MiB，XLSX实际解压内容限制256 MiB和10000个条目。返回明确413，不截断数据。
2. 匹配按200笔分批计算及事务写入；保持生成版本原子发布、失败删除半成品、既有结果和识别负载退让。
3. 增加派生邮件列表索引：状态SQL过滤、加密轻量搜索文档；变动触发修订号，分页按批补齐历史索引，写前复核修订，避免覆盖新数据。关键词仍做子串校验，不存明文搜索内容，不改变语义。
4. 程序生成的Excel数据单元格按文本写入外部字符串，数值不变；原表副本已有公式不改。

验证：上传边界及解压保护、分析期间健康请求响应、索引旧数据及失效刷新、分批等价与失败回收、导出公式和已有标色测试。只跑相关测试，不打Windows包、不提交推送。
