# PST 邮件读取范围与续读

已获用户批准：通过经典 Outlook 读取已挂载 PST，不直接解析 PST。

- 完整枚举各存储根目录，平面节点保留父节点、存储名称与路径；显示访问失败和数量截断，不默默遗漏。
- 多选目录，默认不递归；勾选包含子目录后在 Outlook 工作线程展开并去重。每批上限在所有目录间共享。
- 现有按天历史范围保留，新增按收件日期起止日（含结束日）。指定日期范围只补扫该固定范围；按天模式保留增量读取。
- 固定窗口和复合游标记录已完成目录、当前目录和页游标；重启续读。单目录错误记录路径，其余目录继续；下轮补读失败目录。
- 对跨存档副本，仅在邮件标识及内容指纹一致时合并，保留来源目录；不按金额或提单号去重。
- 前端保持现有样式：目录树、多选计数、日期范围、读取状态。沿用全部付款识别及人工核对流程。

验证顺序：先新增目录、复合分页、日期与副本去重测试并观察失败；实现后运行全部后端测试、前端类型检查和构建。Mac 只能验证模拟 Outlook，真实 COM/PST 需 Windows 验收。
